Atlas Translation

Translate web pages, selected text and PDF files in your browser.

Download a release Source code on GitHub Privacy policy

What it does

  • Translates whole web pages, with Google, Bing, Yandex, DeepL or LibreTranslate.
  • Translator page: type or paste text and see the translation at once, like Google Translate. Save items and keep a history.
  • PDF translation: choose a PDF and translate it on your computer with the Offline helper, when a language pack is installed.
  • Offline translation with the Atlas Helper, which runs on your computer.

Install

The packages and the install steps for each browser are on the releases page.

Atlas Translation is a modified fork of TWP - Translate Web Pages by FilipePS. Translation services belong to their owners.
